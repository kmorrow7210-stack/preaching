# Current Sermon Transcripts

Place transcripts of **recent, current** sermons here.

- Only transcripts in this folder should be used to update `voice/Kyle-Preaching-Voice-Profile.md` and calibrate drafting style.
- Use consistent naming: `YYYY-MM-DD-short-title.md` (or `.txt`).
- When an older season of preaching no longer reflects Kyle's current style, move its transcripts to `voice/transcripts/archive/` so they remain available for growth comparison without skewing active drafts.
